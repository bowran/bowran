## Ephemeral environments.
### Provision. Configure. Vanish.

Cloud environments have a habit of outliving their purpose. A resource group spun up for a two-day test sits there for eight months, quietly billing.

**ephemeral-environment-QOL** solves this with Terraform. Describe the environment, give it a TTL, and it provisions fully configured — then destroys itself when the clock runs out. No cleanup ticket. No orphaned resources. No surprise invoice.

Built on Azure. Written in Shell and HCL.
[View the repository →](https://github.com/bowran/ephemeral-environment-QOL)
